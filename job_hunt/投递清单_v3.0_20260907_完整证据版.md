### 1.1 链接实测方法与判定口径

- 工具：`tools/check_links.py`（v2.0 存量 75 条）、`tools/check_links_round2.py`（本轮新检索 44 条）
- 请求：Python `requests`，自定义 Chrome UA + `zh-CN`，超时 20–25 秒，跟随重定向
- 判定：**OK** = HTTP < 400；**BLOCKED** = 403/405/429/503（疑似反爬，需浏览器人工确认）；**DEAD** = 404 或 DNS/连接失败/超时；**NO_URL** = 该行无链接
- 证据文件：`job_hunt/evidence/link_check_result.csv`（75 条）、`job_hunt/evidence/link_check_result_round2.csv`（44 条）
- 第一轮结果：OK 56 / NO_URL 18 / DEAD 1　→　第二轮针对 18 条缺口与新发现链接补测：OK 42 / DEAD 2
- **局限说明**：HTTP 200 仅证明「页面可达」，不等于该岗位此刻仍在招；岗位是否开放须以官网职位列表为准。
